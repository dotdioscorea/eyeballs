Eyeballs 1.0 (2) — provider sign-in update

Codex now uses its native CLI-compatible account login, fixing the grant mismatch in build 1. Usage access errors no longer incorrectly say your connection has expired. Saved accounts try one token refresh before reporting an access failure.

Claude and Grok now have native system-browser sign-in flows instead of unavailable placeholders. Each provider supports separate personal/work account connections with isolated Keychain records. Claude requests profile access. Grok verifies personal/team identity and uses its direct billing API.

Automated checks cover account isolation, persistence, cancellation, signatures, callback security and refresh recovery. Completed fresh browser login → live usage remains unverified until account authentication is completed; existing CLI-session API probes are separate from that check.

Please update from build 1, then connect an account. Save connection is enabled only after its live usage request succeeds. Widgets show saved readings; preview data never populates widgets.
